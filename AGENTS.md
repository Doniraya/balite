## Проект: Balite (карточный рогалик для Яндекс Игр и ВК Игр)

Разработка лёгкой браузерной карточной игры (**Balite**) в сеттинге **«Гильдия приключенцев»** (исэкай-фэнтези с управляющей Мирой) под Яндекс Игры, VK Игры, OK и VK Play с сохранением глубокой карточной математики, экономики и тактильной отдачи. Технологический стек: TypeScript (`strict: true`), Vite (`base: './'`), Vitest (`jsdom`), гибридный рендер (DOM + SVG + CSS 3D + Canvas), `PlatformBridge` (`src/platform/`).

## Цель проекта (Project Goal)

1. **Высокая вовлечённость и отзывчивость:** плавная работа как на смартфонах `720×1280` (портрет `9:16` с учётом безопасных зон `safe-area` и системных отступов ВК `VKWebAppUpdateInsets`), так и на широких ПК-экранах (`>= 960px`, двухколоночная раскладка), быстрый старт с загрузочным экраном 0-го кадра, пошаговый автосейв и мгновенное продолжение забега.
2. **Кроссплатформенный веб-слой:** единый фасад `PlatformBridge` (`src/platform/`) с ленивой загрузкой SDK и универсальными сохранениями.
3. **Беспрепятственная модерация:** 100% соответствие официальным требованиям площадок (`6+`/`12+` возрастной рейтинг в сеттинге «Гильдия приключенцев» без казино/покера/оккультных терминов) с первого релиза.

## Политика разработки (Policy)

- **Simplicity First:** минимальный чистый код, решающий задачу. Чистая логика игры изолируется в `src/engine/` без зависимостей от DOM.
- **Cross-Platform First:** интерфейс проектируется под мобильные устройства (`touch`, крупные зоны нажатия `>= 44px`, защита от свайпа закрытия при перетаскивании карт, без обязательного hover) и широкий десктоп.
- **Strict Compliance:** любые изменения механик, звука, рекламы, возраста и сохранений сверяются с дорожной картой `docs/superpowers/specs/2026-11-12-desktop-ui-pacing-epics.md`, документацией Яндекс Игр (`docs/README.md`), документацией VK Игр (`docs/vk-games/README.md`) и GDD (`docs/gdd/balite-gdd.md`).
- **Surgical Changes:** точечные правки кода, отсутствие нерелевантного рефакторинга.

- **Верификация UI в браузере и техническая проверка:** для любых проверок интерфейса в браузере (открытие локальной игры, навигация, снятие скриншотов, проверка вёрстки и консоли) агент обязан использовать встроенный браузерный субагент (`browser` / `/browser`, `invoke_subagent` с `TypeName: "browser"`, свободно выбирая любую доступную модель на своё усмотрение), не используя MCP `chrome-devtools`. Проверку интерфейса обязательно совмещать с программной верификацией через `npm test`, `npm run typecheck` и `npm run build`.

## Критические грабли (Known pitfalls)

- **Game Ready сигнал:** игра обязана вызвать `platformBridge.ready()` (внутри `ysdk.features.LoadingAPI.ready()`) сразу после того, как завершена загрузка интерфейса и игра готова к взаимодействию.
- **Ленивая загрузка SDK:** `/sdk.js` загружается лениво в `YandexAdapter`, без блокирующего `<script src="/sdk.js">` в `index.html`.
- **Глушение звука (Mute on Blur / Ad):** звук должен полностью выключаться при переключении вкладки/сворачивании (`visibilitychange`, `VKWebAppViewHide`) и во время показа рекламы (`onAdStart` -> звук заглушен, `onAdEnd` -> звук восстановлен).
- **Облачные сохранения и лимит VK Storage (`2236` символов):** в `VKWebAppStorageSet` сериализованный JSON экранируется, поэтому безопасный потолок одного ключа — `<= 2200` символов (`BALITE_MAX_STORAGE_BYTES = 2200`). Мета-прогресс хранится компактно в основном ключе `balite_save_v1`, а снимок активного забега автоматически разбивается на чанки `<= 2000` символов (`balite_save_v1_r0.._rN`) с проверкой контрольной суммы.
- **Ссылки и техподдержка по площадкам:** внутри игры запрещены кнопки соцсетей (`Discord`, `X`) и сторонние внешние ссылки. На **Яндекс Играх** в окне «Титры / Об игре» выводится только чистый текст без ссылок; на **VK Играх и Одноклассниках** в этом же окне обязательно отображается контакт техподдержки (согласно п. 4.9 правил ВК).
