# Установка и использование







YandexGamesSDK — это плагин для движка Construct 3, предоставляющий удобный доступ к API Яндекс Игр.

Подключение SDK является обязательным условием для успешного прохождения модерации.

Плагин предоставляет следующие возможности:

- Визуальные блоки для полноценного взаимодействия с Яндекс Играми.
- Использование SDK Яндекс Игр в блоках JavaScript.
- Гибкая локализация текста и спрайтов.
- Вспомогательные возможности для удобства разработки.

## Установка {#install}

1. Скачайте последнюю версию плагина в [GitHub](https://github.com/yandex-games-plugins/construct3/tags){.external}.

2. Откройте Construct 3.

3. Перейдите в **Меню** → **Вид** → **Менеджер дополнений**.

4. В появившемся окне нажмите **Установка нового дополнения** и выберите скачанный `.c3addon` файл.

![Скриншот Construct 3: нажата кнопка «MENU» → «View» → «Addon manager». Открыто всплывающее окно «Addon manager», в нем выделена кнопка «Install new addon...» в левом нижнем углу.](https://yandex.ru/dev/games/_images/construct-3/about/addon-install.webp)

## Добавление в проект {#add}

Чтобы начать пользоваться плагином Яндекс Игр:

1. Нажмите правой кнопкой по макету и выберите **Вставить новый объект**.

2. В появившемся меню пролистайте до раздела **Платформы и API**, выберите плагин YandexGamesSDK и нажмите **Вставить**.

![Видео Construct 3: на сером экране пользователь нажимает ПКМ, а затем в контекстном меню выбирает «Insert new object». Во всплывающем окне «Create new object type» пользователь листает список, в конце списка в разделе «Platform specific» выбирает «YandexGamesSDK» и затем нажимает кнопку «Insert» в правом нижнем углу окна.](https://yandex.ru/dev/games/_images/construct-3/about/insert-sdk.gif)

После этого плагин будет добавлен в ваш проект и вы сможете использовать SDK Яндекс Игр.
