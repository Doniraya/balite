# Адаптивный текст







AdaptiveText — это дополнительный плагин для отображения текста с возможностью содержания подстраиваться под заданные границы.

Плагин адаптирует длинные никнеймы игроков, которые не помещаются на экран, и тексты, удлинившиеся после локализации.

![Видео: на сером фоне пользователь масштабирует поле для введения текста. Текст внутри поля изменяется соответственно, не выходя за границы.](https://yandex.ru/dev/games/_images/construct-3/adaptive-text/example-1.gif) ![Видео: на сером фоне фиолетовый прямоугольник, в него пользователь вводит текст «VeryLongUsername». Одновременно с вводом текста уменьшается и его кегель — чем длиннее текст, тем он мельче. При этом текст всегда остается внутри фиолетового прямоугольника.](https://yandex.ru/dev/games/_images/construct-3/adaptive-text/example-2.gif)

Скачать актуальную версию плагина AdaptiveText вы можете в [GitHub](https://github.com/yandex-games-plugins/construct3/releases){.external}.
