# Удаленная конфигурация







Для получения удаленной конфигурации флагов (Remote Config) используйте действие **Запросить удаленную конфигурацию** совместно с **Удаленная конфигурация загружена** и **Ошибка загрузки удаленной конфигурации**. Рекомендуем запрашивать флаги один раз на старте игры.

Чтобы получить значения из удаленной конфигурации, используйте выражение **Флаг**.

## Локальная конфигурация {#local}

Рекомендуем всегда зашивать локальную конфигурацию флагов в код игры на случай, если не удастся получить удаленную конфигурацию с сервера (например, по причине сетевых проблем в метро). Это повышает работоспособность игры.

Для этого используйте действие **Задать стандартное значение ключа**.

## Клиентские параметры {#client}

Для описания клиентских параметров используйте действие **Задать особенность клиента**. Они будут переданы при запросе удаленной конфигурации.
