# База знаний и документация VK Games (VK для разработчиков)

Полный локальный архив документации игровой платформы **VK Games**, библиотеки **VK Bridge**, публикации в **Одноклассниках**, платёжного API и **Правил платформы** (выгружено с `https://dev.vk.com/ru/guide`, 232 документа).

## Быстрый чек-лист ключевых требований к игре VK Games

| Область | Что проверить перед модерацией | Документ |
| :--- | :--- | :--- |
| **Инициализация VK Bridge** | В начале загрузки отправляется событие `VKWebAppInit` | [games/getting-started.md](games/getting-started.md) |
| **Правила площадки** | Соблюдены Правила платформы и Правила размещения VK Mini Apps (включая раздел 5.1 по рекламе) | [rules/rules.md](rules/rules.md), [rules/mini-apps-rules.md](rules/mini-apps-rules.md) |
| **Модерация каталога** | Нет ошибок на выбранных платформах, есть отключение звука, техподдержка, обучение, основной язык — русский, уникальное название/игра | [games/catalog/moderation.md](games/catalog/moderation.md) |
| **Сворачивание и восстановление** | Корректная обработка `VKWebAppViewHide` и `VKWebAppViewRestore` (пауза звука/игрового процесса и восстановление) | [games/how-to/handle-minimize-and-restore-events.md](games/how-to/handle-minimize-and-restore-events.md) |

| **Платежи и валюта** | Игровая валюта/покупки только за голоса/ОКи, проверка подписи/уведомлений на сервере при наличии IAP | [games/monetization/digital-goods.md](games/monetization/digital-goods.md) |
