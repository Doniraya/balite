# Получение информации о товаре (get_item)

ВКонтакте отправляет уведомление `get_item` серверу приложения (игры или мини-приложения) перед показом окна [покупки](../virtual-goods/vk.md#Обмен данными). Сервер в своём ответе должен предоставить информацию, которая будет отображена в окне покупки.

## Уведомление

Данные приходят в теле запроса в виде строки, содержащей пары `параметр=значение`. Пары разделены символами `&`.

### Пример

`app_id=1524456&item=sale_item_1&lang=ru_RU&notification_type=get_item_test&order_id=2044594&receiver_id=1&user_id=1&version=5.132&sig=a71ec5b6c78940fa47a83796ee983ab6`

### Параметры

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `app_id` | `integer` | Идентификатор приложения, в котором происходит покупка. Значение должно совпадать с идентификатором, который отображается в [настройках приложения](https://dev.vk.com/ru/mini-apps/management/settings#%D0%9D%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B8). |
| `item` | `string` | Идентификатор товара, который использует ваше приложение и который оно передало событию [`VKWebAppShowOrderBox`](../../../bridge/VKWebAppShowOrderBox.md) библиотеки VK Bridge. [Пример вызова события](../virtual-goods/vk.md#Шаг 3. Вызовите событие VK Bridge для показа окна покупки). Сервер в своём ответе должен предоставить информацию о покупаемом товаре, которая будет отображена в окне покупки. |
| `lang` | `string` | Язык пользователя, создавшего заказ. Возможно одно из следующих значений: • `ru_RU` — русский • `uk_UA` — украинский • `be_BY` — белорусский • `en_US` — английский. Ваш сервер может проверять значение этого параметра, чтобы [возвращать описание товара на языке пользователя](overview.md#Поддержка многоязычных интерфейсов). |
| `notification_type` | `string` | Тип уведомления. В рабочем режиме прохождения платежей параметр равен `get_item`, в [тестовом](../testing.md) — `get_item_test`. |
| `order_id` | `integer` | Идентификатор заказа в системе платежей ВКонтакте. |
| `receiver_id` | `integer` | Идентификатор пользователя, который получит заказ. В данный момент совпадает с `user_id`, но в будущем может отличаться. |
| `user_id` | `integer` | Идентификатор пользователя, создавшего заказ. |
| `version` | `string` | Версия формата данных уведомления. Совпадает с версией, указанной в настройках приложения в разделе **Платежи** в поле [Версия API](https://dev.vk.com/ru/api/payments/subscriptions#%D0%A8%D0%B0%D0%B3%202.%20%D0%A3%D0%BA%D0%B0%D0%B6%D0%B8%D1%82%D0%B5%20%D0%B0%D0%B4%D1%80%D0%B5%D1%81%20%D0%BE%D0%B1%D1%80%D0%B0%D1%82%D0%BD%D0%BE%D0%B3%D0%BE%20%D0%B2%D1%8B%D0%B7%D0%BE%D0%B2%D0%B0%20%D0%B2%20%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B0%D1%85%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F). Параметр используется только для версии `5.132` и более поздних. |
| `site` | `string` | Площадка, на которой пользователь совершает покупку. `VK` — ВКонтакте. Значение по умолчанию `OK` — в Одноклассниках. |
| `sig` | `string` | Подпись параметров уведомления. Позволяет защититься от подмены параметров третьими лицами. Подробнее — в разделе [Подпись параметров](overview.md#Подпись параметров). |

Строковые значения закодированы в URL-encoded формате, применяемом в PHP. Вам необходимо [раскодировать их](overview.md#Работа со строковыми данными) перед обработкой.

## Ответ сервера

По идентификатору товара, указанному в параметре запроса `item`, сервер должен вернуть информацию о товаре. Если запрашиваемый товар отсутствует, надо вернуть ошибку с [кодом `20`](overview.md#Коды ошибок) («Товара не существует»).

### Пример

```json
{
  "response": {
    "title": "300 изумрудов",
    "price": 27,
    "photo_url": "https://my-app.example.com/sale-item-1.png",
    "discount": 3,
    "item_id": "sale_item_1",
    "expiration": 3600
  }
}
```

### Параметры

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `title` *обязательное* | `string` | Название товара для отображения в диалоговом окне покупки. Максимальная длина — 48 символов. |
| `photo_url` | `string` | Полный URL изображения товара (включая адрес сервера и протокол). Рекомендуемый размер изображения — 75×75 px. |
| `price` *обязательное* | `integer` | Стоимость товара в [голосах ВКонтакте](../../../mini-apps/glossary.md#Голос). |
| `discount` | `integer` | Размер скидки на товар в голосах. Значение скидки должно быть в пределах от `1` до `1 000` и должно быть меньше, чем стоимость товара, указанная в поле `price`. Если скидка не предусмотрена, верните `0` или не указывайте параметр в ответе. |
| `item_id` | `string` | Идентификатор товара, используемый в вашем приложении. Передайте то же значение, которое было получено в параметре `item` уведомления. |
| `expiration` | `integer` | Период времени в секундах, в течение которого платформа хранит в кеше информацию о товаре и покупателе. Диапазон значений: от `600` до `604 800` секунд. • Если параметр не передан или указано значение от `0` до `599`, платформа установит период кеширования `3600` секунд. • Если указано значение больше `604 800`, платформа установит период кеширования `604 800` секунд. |

> **Совет**. Рекомендуем всегда использовать [кеширование](overview.md#Кеширование информации о товарах и подписках) и проверять платежи в рамках выбранного периода `expiration`. Пока информация о товаре хранится в кеше, ВКонтакте использует эти данные и не отправляет уведомления `get_item` серверу приложения. Это ускоряет процесс покупки и снижает нагрузку на сервер приложения.

Значения в полях ответа можно изменять в зависимости от языка пользователя, указанного в параметре `lang` запроса. То есть для одного и того же идентификатора товара можно возвращать разные названия и изображения в зависимости от языка.

Данные для разных языков пользователя кешируются отдельно друг от друга.

### Обработка ошибок

В случае ошибки нужно вернуть объект следующей структуры:

```json
{
  "error": {
        "error_code": 20, 
        "error_msg": "Товара не существует",
        "critical": true
    }
}
```

Подробнее о полях объекта и кодах ошибок — в разделе [Формат ответа при ошибке](overview.md#Формат ответа при ошибке).
