# Платежи виртуальной валютой

Продажа виртуальных ценностей — один из способов монетизации игр и мини-приложений. Продавать такие товары можно только за [голоса ВКонтакте](../../mini-apps/glossary.md#Голос) или [ОКи в Одноклассниках](../../mini-apps/glossary.md#ОКи).

[Продажа](https://dev.vk.com/ru/mini-apps/monetization/payments#%D0%9F%D1%80%D0%BE%D0%B4%D0%B0%D0%B6%D0%B0%20%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%BE%D0%B2%20%D0%B7%D0%B0%20%D0%B4%D0%B5%D0%BD%D1%8C%D0%B3%D0%B8) реальных товаров и услуг за денежные средства возможна только в мини-приложениях. Для выполнения таких платежей используйте другой механизм — [VK Pay](https://dev.vk.com/ru/pay/getting-started).

Подробнее об особенностях продажи товаров в приложениях:

- [Продажа игровых товаров](../../games/monetization/digital-goods.md)
- [Продажа товаров в мини-приложениях](https://dev.vk.com/ru/mini-apps/monetization/payments)

## Виды платежей

Поддерживаются следующие виды платежей:

- **Разовые списания** используются для покупки товаров.
- **Подписки** — для покупки и обновления подписок.

Вам не надо создавать диалоговые окна для подтверждения покупки или отсылать API-запросы своему серверу приложений. Воспользуйтесь встроенными функциями.

Обмен данными между приложением и площадкой имеют некоторые отличия в Одноклассниках и ВКонтакте. Используйте пошаговые инструкции для каждой площадки:

- [Покупка виртуальных ценностей ВКонтакте](virtual-goods/vk.md)
- [Покупка виртуальных ценностей в Одноклассниках](virtual-goods/ok.md)
- [Покупка подписок ВКонтакте](subscriptions/vk.md)
- [Покупка подписок в Одноклассниках](subscriptions/ok.md)
