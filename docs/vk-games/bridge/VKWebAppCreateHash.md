# VKWebAppCreateHash

`VKWebAppCreateHash` создаёт криптографическую подпись для данных с помощью защищённого ключа доступа из настроек мини-приложения или игры. Этот ключ известен администраторам приложения и неизвестен посторонним.

- [Защищенный ключ (настройки мини-приложений)](https://dev.vk.com/ru/mini-apps/settings/development/keys#%D0%97%D0%B0%D1%89%D0%B8%D1%89%D1%91%D0%BD%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BB%D1%8E%D1%87)
- [Защищенный ключ (настройки игр)](../games/settings/development/keys.md#Защищённый ключ)

Вы можете использовать подпись для обнаружения подмены данных, которые приходят в запросах на сервер мини-приложения или игры. Код на сервере вычисляет подпись для полученных данных и сравнивает её с переданной подписью, чтобы убедиться, что запрос пришёл от доверенного источника. Подробности — в разделе [Проверка подлинности данных](../mini-apps/development/protect-with-signature.md).

## Пример

```javascript
bridge.send('VKWebAppCreateHash', {
    payload: 'param1=value1;param2=value2'
  })
  .then((data) => { 
    if (data.sign) {
      // Ключ сгенерирован
    }
  })
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

## Параметры

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `payload` *необязательное* | `string` | Строка, для которой надо сгенерировать подпись. Если вы не укажете это значение, платформа ВКонтакте сгенерирует подпись для пустой строки. Это может быть полезно при отправке на сервер каких-либо команд, не содержащих данных. |

## Результат

Проверить результат можно:

- Используя объект [`Promise`](#Объект Promise), который возвращается вызовом `bridge.send(...)`.
- С помощью [событий](#События) `VKWebAppCreateHashResult` и `VKWebAppCreateHashFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](getting-started.md#Обработка результата).

### Объект `Promise`

Если обращение к платформе прошло успешно, управление будет передано в `then`-обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующими полями:

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `sign` | `string` | Сформированная подпись данных. Алгоритм формирования рассмотрен в разделе [Проверка подлинности данных](../mini-apps/development/protect-with-signature.md). |
| `payload` | `string` | Та же самая строка, которая была передана в параметре `payload` при вызове события. |
| `ts` | `integer` | Время, когда подпись была сгенерирована, в формате [Unix Timestamp](https://www.unixtimestamp.com/). |

> Для проверки подписи передайте серверу и саму подпись, и время её создания. Подробности — в разделе [Проверка подлинности данных](../mini-apps/development/protect-with-signature.md).

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](getting-started.md#Обработка ошибок), общий для всех событий VK Bridge.

### События

#### `VKWebAppCreateHashResult`

Сигнализирует, что подпись была сгенерирована. В обработчик события на стороне пользователя передаются следующие данные:

```javascript
{
  detail: {
    type: "VKWebAppCreateHashResult",
    data: {
      sign: "m7TwcoveOwy4BE180UCTwyTkPApprYP81RjrOEuQcos",
      payload: "param1=value1;param2=value2",
      ts: 1664541985
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при [успешном выполнении промиса](#Объект Promise).

#### `VKWebAppCreateHashFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке](getting-started.md#Обработка ошибок), общий для всех методов VK Bridge.
