# VKWebAppGetAuthToken

`VKWebAppGetAuthToken` отображает запрос на доступ к данным пользователя для мини-приложения или игры.

**Важно.** Адрес, с которого запрашивается доступ, должен совпадать с URL из настроек мини-приложения или игры. Чтобы получить этот адрес, библиотека VK Bridge использует значение `window.location`.

- [Размещение (настройки мини-приложения)](https://dev.vk.com/ru/mini-apps/settings/general/placement)
- [Размешение (настройки игры)](../games/settings/general/placement.md)

## Пример

```javascript
bridge.send('VKWebAppGetAuthToken', { 
  app_id: 6909581, 
  scope: 'friends,status'
  })
  .then( (data) => { 
    if (data.access_token) {
      // Ключ доступа пользователя получен
    }
  })
  .catch( (error) => {
    // Ошибка
    console.log(error);
  });
```

## Совместимость

| Площадки | Платформы |
| :--- | :--- |
| ВКонтакте | Android, iOS, Mobile Web, Web |
| Одноклассники | Android, iOS, Mobile Web, Web |

## Параметры

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `app_id` *обязательное* | `integer` | Идентификатор мини-приложения или игры. |
| `scope` *обязательное* | `string` | Запрашиваемые права доступа и разрешения. Укажите одну или несколько констант ниже через запятую: • `friends` — доступ к списку друзей пользователя. • `photos` — доступ к фотографиям в профиле пользователя. • `video` — доступ к видео в профиле пользователя. • `stories` — доступ к историям, созданным пользователем. • `pages` — доступ к вики-страницам пользователя. • `status` — доступ к статусу пользователя. • `messages` — разрешение на использование API-запросов для работы с сообщениями пользователя. С 2019 года доступ не выдаётся. [Подробнее об ограничении доступа](https://dev.vk.com/ru/reference/roadmap#%D0%9E%D0%B3%D1%80%D0%B0%D0%BD%D0%B8%D1%87%D0%B5%D0%BD%D0%B8%D0%B5%20Messages%20API). • `wall` — возможность использовать API-запросы для работы со стеной пользователя. • `docs` — доступ к документам пользователя. • `groups` — доступ к информации о сообществах пользователя. • `stats` — доступ к статистике сообществ и приложений, которые администрирует пользователь. • `group_messages` — разрешение на отправку пользователю сообщений от лица сообщества, которое указано как официальное сообщество в настройках [мини-приложения](https://dev.vk.com/ru/mini-apps/settings/general/information) или [игры](../games/settings/general/information.md). • `market` — доступ к товарам, добавленным пользователем на платформу. Если вы передадите пустую строку в параметре `scope`, платформа вернёт ключ доступа для прав, запрошенных ранее. **Важно.** Если вы укажете неподдерживаемое значение в `scope`, произойдёт ошибка. |
| `append_local` *необязательное* | `boolean` | Указывает, для какой площадки нужно получить ключ. Возможные значения: • `true` — получить ключ для площадки, которая использует SDK (например, Одноклассники). • `false` — получить ключ для ВКонтакте. Значение по умолчанию. Ключ доступа вернётся в ответе в поле `local_access_token`. |

## Результат

Если пользователь разрешает доступ к данным своего профиля, событие вернёт [ключ доступа](../api/access-token/getting-started.md) для работы с API. Если пользователь отклоняет запрос, вернётся ошибка.

Проверить результат можно:

- Используя объект [`Promise`](#Объект Promise), который возвращается вызовом `bridge.send(...)`.
- С помощью [событий](#События) `VKWebAppAccessTokenReceived` и `VKWebAppAccessTokenFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](getting-started.md#Обработка результата).

### Объект `Promise`

Если обращение к платформе прошло успешно, управление будет передано в `then`-обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующими полями:

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `access_token` | `string` | Ключ доступа пользователя. |
| `local_access_token` | `string` | Ключ доступа для площадки, использующей SDK. |
| `scope` | `string` | Список прав доступа, которые пользователь выдал. Эта строка может отличаться от строки, переданной в поле `scope` при вызове события. |
| `expires` | `integer` | Дата и время в формате [Unix Timestamp](https://www.unixtimestamp.com/), когда время жизни ключа истечёт. |
| `status` | `boolean` | Индикатор, что событие выполнилось успешно (всегда `true`). |

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](getting-started.md#Обработка ошибок), общий для всех событий VK Bridge.

### События

#### `VKWebAppAccessTokenReceived`

Сигнализирует, что ключ доступа пользователя получен. В обработчик события на стороне пользователя передаются следующие данные:

```javascript
{
  detail: {
    type: "VKWebAppAccessTokenReceived",
    data: {
      access_token: "vk12XyJnfX7mG7PE1MBW...6KV4dcdjVjzwwwSDkX",
      expires: 1665151371,
      request_id: "5_u5w",
      scope: "docs",
      status: true
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при [успешном выполнении промиса](#Объект Promise).

#### `VKWebAppAccessTokenFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке](getting-started.md#Обработка ошибок), общий для всех методов VK Bridge.
