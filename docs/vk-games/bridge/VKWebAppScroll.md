# VKWebAppScroll

`VKWebAppScroll` прокручивает окно браузера по вертикали.

## Пример

```javascript
bridge.send('VKWebAppScroll', {
  top: 1,
  speed: 600
  }) 
  .then((data) => { 
    if (data.top) {
      // Окно браузера прокручено
    }
  })
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

## Совместимость

| Площадки | Платформы |
| :--- | :--- |
| ВКонтакте | Mobile Web, Web |
| Одноклассники | Mobile Web, Web |

## Параметры

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `top` *обязательное* | `integer` | Смещение прокрутки относительно нулевой координаты окна. Например, чтобы прокрутить окно до самого верха страницы, необходимо передать значение `0`. |
| `speed` *необязательное* | `integer` | Скорость анимации в миллисекундах. Значение по умолчанию: `0`. |

## Результат

Проверить результат можно:

- Используя объект [`Promise`](#Объект Promise), который возвращается вызовом `bridge.send(...)`.
- С помощью [событий](#События) `VKWebAppScrollResult` и `VKWebAppScrollFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](getting-started.md#Обработка результата).

### Объект `Promise`

Если обращение к платформе прошло успешно, управление будет передано в `then`-обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующим полем:

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `top` | `integer` | Текущее положение прокрутки. |
| `height` | `integer` | Высота окна после прокрутки пользователем или событием. |

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](getting-started.md#Обработка ошибок), общий для всех событий VK Bridge.

### События

#### `VKWebAppScrollResult`

Сигнализирует, что окно браузера прокручено. В обработчик события на стороне пользователя передаются следующие данные:

```javascript
{
  detail: {
    type: "VKWebAppScrollResult",
    data: {
      top: 1, 
      height: 2040 
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при [успешном выполнении промиса](#Объект Promise).

#### `VKWebAppScrollFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке](getting-started.md#Обработка ошибок), общий для всех методов VK Bridge.
