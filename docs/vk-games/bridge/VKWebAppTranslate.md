# VKWebAppTranslate

Используйте `VKWebAppTranslate` для [перевода текстов](https://dev.vk.com/ru/mini-apps/development/translate) на другой язык.

## Пример

```javascript
bridge.send('VKWebAppTranslate', {
   texts: [
        'Привет, как дела?',
        'Была возможность посмотреть книгу, про которую я писал?'
   ],    
   translation_language: 'ru-en'
  })
  .then((data) => { 
    // Переведённые строки
    console.log(data.result.texts);
  })
  .catch((error) => {
    // Ошибка
    console.log(error);
  });
```

## Параметры

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `texts` *обязательное* | `string[]` | Массив строк для перевода. На количество элементов массива и их размер накладываются [ограничения](#Особенности использования). |
| `translation_language` *обязательное* | `string` | Язык, на который будет выполнен перевод, например `en`, либо языковая пара, которая обозначает исходный и целевой язык, например `ru-en`. Если вы указываете только целевой язык, то исходный язык платформа определит автоматически. [Подробнее](#Особенности использования) Для обозначения языков используйте следующие значения (строго в нижнем регистре): • `en` — английский. • `es` — испанский. • `pt` — португальский. • `ru` — русский. |

## Результат

Проверить результат можно:

- Используя объект [`Promise`](#Объект Promise), который возвращается вызовом `bridge.send(...)`.
- С помощью [событий](#События) `VKWebAppTranslateResult` и `VKWebAppTranslateFailed`.

[Подробнее о проверке результатов при вызовах VK Bridge](getting-started.md#Обработка результата).

### Объект `Promise`

Если обращение к платформе прошло успешно, управление будет передано в `then`-обработчик объекта `Promise`. В качестве ответа платформа возвращает объект со следующим полем:

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `texts` | `string[]` | Массив переведённых строк. Каждая из них соответствует отдельной строке в параметре `texts` запроса. |
| `source_lang` | `string` | Строковая константа, которая обозначает язык исходного текста. Используются те же значения, которые указаны в описании параметра `translation_language`. |

Если при обращении к платформе произошла ошибка, управление передаётся в метод `catch`. В качестве ответа платформа возвращает [объект с информацией об ошибке](getting-started.md#Обработка ошибок), общий для всех событий VK Bridge.

Ошибки, наиболее часто возникающие при работе события `VKWebAppTranslate`:

| Ошибка | Описание |
| :--- | :--- |
| `9 Flood control` | Слишком частый вызов события. |
| `11101 Can't translate` | Перевод невозможен. Например, когда весь текст — комбинация символов, которой не соответствует ни одно слово или фраза в целевом языке. |
| `11102 Multiple source languages. Only one allowed.` | При вызове был указан только целевой язык для перевода, и алгоритм перевода сообщает об использовании разных языков в оригинальном тексте. Чтобы обойти ошибку, попробуйте указать языковую пару в параметре `translation_language`. |

### События

#### `VKWebAppTranslateResult`

Сигнализирует, что текст был переведён. В обработчик события на стороне пользователя передаются следующие данные:

```javascript
{
  detail: {
    type: "VKWebAppTranslateResult",
    data: {
      texts: [
        'Hi. How are you?',
        'Did you get a chance to see the book I was writing?'
      ],
      source_lang: 'ru'
    }
  }
}
```

Передаваемый объект подобен объекту, возвращаемому при [успешном выполнении промиса](#Объект Promise).

#### `VKWebAppTranslateFailed`

Информирует об ошибке, которая произошла при взаимодействии с платформой.

В обработчик события на стороне пользователя передаётся [объект с информацией об ошибке](getting-started.md#Обработка ошибок), общий для всех методов VK Bridge.

## Особенности использования

- На массив строк, который передаётся событию в параметре [`texts`](#Параметры), накладываются следующие ограничения:
  - Массив может содержать не более 10 элементов.
  - Размер каждой строки — не более 1024 символов.
- Событие нельзя вызывать чаще 10 раз в минуту.
- Пока что автоматические переводы работают только с текстом: cохранение разметки Markdown и HTML не гарантируется. Поддержка языков разметки будет реализована позднее.
- Параметр `translation_language` может указывать только целевой язык для перевода, например `en`. В таком случае платформа попытается определить язык исходного текста автоматически. Эта процедура может работать недостаточно точно на коротких текстах. Поэтому мы рекомендуем, когда это возможно, указывать языковую пару, например `ru-en`.
