# Запуск игры

Сразу после добавления в панели управления игру могут запускать только её администраторы. Чтобы игра стала доступна всем пользователям, нужно изменить [настройки видимости](#Настройки в панели управления). Для игр в Одноклассниках игра станет доступна всем только после прохождения модерации в каталог.

## Доступность игры

Видимость игры настраивается в разделе [Размещение](settings/general/placement.md) и также зависит от публикации в каталоге.

### Настройки в панели управления

- **Состояние: Отключено**. Состояние игры сразу после создания. ВКонтакте игра с таким состоянием доступна только администраторам. Запустить игру в Одноклассниках может только создатель.
  Чтобы опубликовать игру в Одноклассниках, нужно привязать OK ID в разделе [Другие площадки](settings/general/other-sites.md). Игра станет доступна в Одноклассниках в течение 15 минут.
- **Состояние: Включено**. Игра ВКонтакте станет доступна по ссылке всем пользователям. В Одноклассниках доступ будет только у создателя игры. Чтобы игра стала доступна всем пользователям, нужно пройти [модерацию](settings/moderation.md).

Тестовые сборки можно сделать доступными только для тестировщиков игры. Для этого используйте [тестовые группы](settings/test-groups.md).

Подробнее о добавлении администраторов в игру — в разделе [Панель управления | Администраторы](settings/managers.md#Добавление администратора).

### Публикация в каталоге

- [Публикация в каталоге ВКонтакте](catalog/overview.md) не влияет на доступность игры пользователям. Когда игра опубликована, пользователи могут найти её в каталоге и запустить через интерфейс ВКонтакте. Без публикации они могут пользоваться только прямой ссылкой на игру.
- [Публикация в каталоге Одноклассников](../ok/publishing.md) делает игру доступной для всех пользователей. Её можно найти и запускать из каталога.

### Сводная таблица

Следующая таблица показывает доступность игры пользователям в зависимости от настроек:

| Настройки | Доступность пользователям | Доступность администраторам |
| :--- | :--- | :--- |
| Состояние: Отключено | Игра недоступна | • Всем ВКонтакте • Только создателю в Одноклассниках |
| Состояние: Включено | • Доступна [по прямой ссылке](#В браузере) ВКонтакте • Недоступна в Одноклассниках | • Всем ВКонтакте • Только создателю в Одноклассниках |
| Игра опубликована в каталоге | Доступна [по прямой ссылке](#В браузере) и через UI ВКонтакте и Одноклассников | Всем ВКонтакте и в Одноклассниках |

## Запуск игры

Когда игра попала в каталог, запустить её можно из интерфейса социальной сети. Пока игра не опубликована, используйте другие способы для удобного запуска.

### В браузере

- **По прямой ссылке**. Ссылки на игру можно найти в панели управления:
  ![Ссылки на игру в панели управления](https://sun9-85.userapi.com/Fk8almG2u316IzVtClJ3VGFgsZ8E0CGKnSdfgw/3LiOAnFTzrM.jpg)Ссылки на игру в панели управления
  Чтобы запустить игру в мобильной версии, добавьте в адрес `m`, например: `https://m.vk.com/app535566**` .
- **Через «Закладки» или **Избранное** ВКонтакте.** Запустите игру по прямой ссылке и выберите действие **Сохранить в закладках** или **Добавить в избранное**.
  ![Добавление игры в «Избранное» и закладки](https://sun9-66.userapi.com/dDe38I5M7M8rvF7ULRVD6r64rH_fa0cwMRMXzQ/y47LOajRKdk.jpg)Добавление игры в «Избранное» и закладки![Запуск игры из «Избранного» и закладок](https://sun9-52.userapi.com/2rJfs2WLFWn5n9iAS8hed_jtcmIuTcQffJK5XA/AmmRYuF_aNU.jpg)Запуск игры из «Избранного» и закладок
  - Игру, добавленную в избранное, можно запустить из левого меню.
  - Игру, сохранённую в закладках, можно запустить из пункта **Закладки** в левом меню.

### В мобильном приложении

- **Из личных сообщений.**
  ![Запуск из личных сообщений](https://sun9-64.userapi.com/6u552Y897ogtEUVmVnByLYWap2gG-8Y-DJKdeg/Axqi3NxyTgU.jpg)Запуск из личных сообщений
  > При отправке сообщения мессенджер определяет, что ссылка указывает на игру, и добавляет сниппет игры к сообщению. Вы можете запустить игру, нажав на кнопку в сниппете.
  1. Перейдите в раздел **Мессенджер** и откройте диалог **Избранное** — поместите курсор в поле поиска чатов.
    Затем отправьте ссылку на игру. Её можно [найти](#В браузере) в панели управления игрой.
  2. В мобильном приложении перейдите в диалог **Избранное** и нажмите на отправленную ссылку. ВКонтакте запустит игру в элементе управления WebView.
- **Из списка недавно запущенных ВКонтакте.**
  ![Запуск недавно запущенной игры](https://sun9-77.userapi.com/lKQ3ax2M_IDVGSCjUIpvX1LB5lYC4J9tpDpjtg/mbwx0OgKeYI.jpg)Запуск недавно запущенной игры
  1. [Запустите](#В браузере) игру в десктопной версии сайта ВКонтакте. После этого она попадёт в список игр, которые были запущены недавно.
  2. Откройте мобильное приложение ВКонтакте для Android и перейдите на последнюю вкладку.
  3. Запустите игру из блока **Обзор**.

## Как скрыть игру

Измените **Состояние** на **Отключено**. Игра станет доступна только её администраторам.
