# Параметры запуска

При старте игры или мини-приложения ВКонтакте передаёт им дополнительные параметры, содержащие данные о пользователе и источнике запуска. Значения передаются как URL-параметры на адрес, указанный в настройках игры или мини-приложения.

- [URL запуска игры](../settings/general/placement.md#URL)
- [URL запуска мини-приложения](https://dev.vk.com/ru/mini-apps/settings/general/placement#URL)

Чтобы получить параметры запуска в коде приложения на стороне пользователя, воспользуйтесь одним из способов:

- Извлеките значение свойства `href` объекта `window.location`.
- Вызовите событие [`VKWebAppGetLaunchParams`](../../bridge/VKWebAppGetLaunchParams.md).

## Подпись параметров

Чтобы защититься от подмены значений возможной утечки данных, используйте подпись параметров. Подробности — в разделе [Подпись параметров запуска](parameters-sign.md).

## Параметры

Некоторые параметры передаются только для игр или только для мини-приложений. Это указано в таблице.

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `sign` | `string` | base64-строка — подпись параметров запуска. Используется для обнаружения подмены параметров третьими лицами. Подробнее — в разделе [Подпись параметров запуска](parameters-sign.md). |
| `vk_access_token_settings` | `string` | Список прав доступа пользователя, который запустил приложение. Каждое значение в списке соответствует области данных пользователя, к которой можно получить доступ. Значения в списке разделены запятыми, например `friends,stories,wall`. Список используемых строковых констант приведён в разделе [Права доступа](../../api/privacy.md#Права доступа). |
| `vk_app_id` | `integer` | Идентификатор запущенного приложения из его настроек. Подробнее: • [Где найти ID игры](../settings/overview.md#Где найти ID игры?) • [Где найти ID мини-приложения](https://dev.vk.com/ru/mini-apps/settings/overview#%D0%93%D0%B4%D0%B5%20%D0%BD%D0%B0%D0%B9%D1%82%D0%B8%20ID%20%D0%BC%D0%B8%D0%BD%D0%B8-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F?) |
| `vk_are_notifications_enabled` | `integer` | Информация о разрешённых уведомлениях от приложения: • `0` — отправка уведомлений запрещена. • `1` — отправка уведомлений разрешена. |
| `vk_chat_id` | `string` | Идентификатор чата. Передаётся, если приложение было запущено из чата. |
| `vk_group_id` | `integer` | Идентификатор сообщества, в котором установлено приложение. Передаётся, если мини-приложение: • Запущено с помощью кнопок в сообществе или из блока приложений сообщества. • Запущено по ссылке вида: `vk.com/app6909581_-166562603`. Параметр не используется в играх. |
| `vk_has_profile_button` | `integer` | Информация о том, установил ли пользователь кнопку в профиле, по которой запускается мини-приложение. Значение `1` означает, что пользователь установил кнопку в профиле, иначе параметр не передаётся. Параметр не используется в играх. |
| `vk_is_app_user` | `integer` | Информация о том, установил ли пользователь приложение : • `0` — приложение не установлено. • `1` — приложение установлено. После того, как пользователь впервые запустил игру или мини-приложение, они считаются установленными. |
| `vk_is_favorite` | `integer` | Информация о добавлении приложения в избранное: • `0` — приложение не добавлено в избранное. • `1` — приложение добавлено в избранное. |
| `vk_is_play_machine` | `integer` | `1`, если игра была запущена через [Play Machine](../faq.md#Поддерживаются ли Flash-игры?) (специальное приложение для запуска Flash-игр). В ином случае параметр равен `0` или не передаётся. Параметр не используется в мини-приложениях. |
| `vk_is_recommended` | `integer` | Информация о том, [рекомендовал](https://dev.vk.com/ru/mini-apps/promotion/user-recommendation) ли пользователь, указанный в параметре `vk_user_id`, мини-приложение своим друзьям: • `0` — мини-приложение не порекомендовано. • `1` — мини-приложение порекомендовано. Если параметр не передан, значит, что приложение ещё не порекомендовано. Параметр не используется в играх. |
| `vk_is_widescreen` | `integer` | `1`, если игра запущена в [широкоформатном режиме](../settings/general/display.md#Широкоформатный режим), иначе — `0`. Параметр используется только для [Web-игр](../getting-started.md#Direct Games и Web-игры). Параметр не используется в мини-приложениях. |
| `vk_language` | `string` | Язык пользовательского интерфейса приложения. Возможные значения: • `ru` — русский. • `uk`, `ua` — украинский. • `en` — английский. • `be` — белорусский. • `kz` — казахский. • `pt` — португальский. • `es` — испанский. |
| `vk_platform` | `string` | Платформа, на которой было запущено приложение: • `desktop_web` — десктопная версия сайта ВКонтакте. • `mobile_android` — мобильное приложение ВКонтакте для Android. • `mobile_ipad` — мобильное приложение ВКонтакте для iPadOS. • `mobile_iphone` — мобильное приложение ВКонтакте для iOS. • `mobile_web` — мобильная версия сайта ВКонтакте. Если мини-приложение было запущено из VK Мессенджера: • `desktop_app_messenger` — десктопное приложение VK Мессенджер. • `desktop_web_messenger` — десктопная версия VK Мессенджера (web.vk.me). •`mobile_android_messenger` — мобильное приложение VK Мессенджер для Android. • `mobile_iphone_messenger` — мобильное приложение VK Мессенджер для iOS. Если мини-приложение было запущено не из ВКонтакте или VK Мессенджера, то параметр содержит следующие значения: • `android_external` — приложение для Android. • `iphone_external` — приложение для iOS. • `ipad_external` — приложение для iPadOS. • `mvk_external` — сайт, открытый в мобильном браузере. • `web_external` — сайт, открытый в десктопном браузере. |
| `vk_profile_id` | `integer` | Идентификатор пользователя, по кнопке в профиле которого запускается мини-приложение. Если мини-приложение запущено не по кнопке в профиле, параметр не передаётся. Параметр не используется в играх. |
| `vk_ref` | `string` | Источник запуска приложения. Подробнее — в разделе [Значения параметра vk_ref](parameters/vk_ref.md) |
| `vk_request_key` | `string` | Используется при старте игры из [запроса о помощи](../promotion/game-mechanics/requests.md) или [приглашения](../promotion/game-mechanics/invites.md) друга. Указывает ключ запроса или приглашения. Это то же самое значение, которое было передано в параметре `requestKey` при вызове события [`VKWebAppShowRequestBox`](../../bridge/VKWebAppShowRequestBox.md) или [`VKWebAppShowInviteBox`](../../bridge/VKWebAppShowInviteBox.md) библиотеки [VK Bridge](../../bridge/overview.md). Используйте это значение в игре, чтобы предусмотреть сценарий, соответствующий запросу или приглашению, а также для отслеживания конверсии. Параметр не используется в мини-приложениях. |
| `vk_testing_group_id` | `integer` | Идентификатор тестовой группы, в которой состоит пользователь. Если пользователь не состоит в тестовой группе, параметр не передаётся. |
| `vk_ts` | `integer` | Время генерации подписи параметров запуска. Подпись передаётся в параметре `sign`. |
| `vk_user_id` | `integer` | Идентификатор пользователя, запустившего приложение. Параметр `vk_user_id` нужно использовать для авторизации пользователя в мини-приложении или игре. Чтобы проверить подлинность полученных данных, вычислите подпись и сравните с полученным значением sign. |
| `vk_viewer_group_role` | `string` | Роль пользователя в сообществе, из которого запущено мини-приложение: • `admin` — администратор или создатель сообщества. • `editor` — редактор сообщества. • `member` — подписчик сообщества. • `moder` — модератор сообщества. • `none` — не состоит в сообществе. Информация о сообществе возвращается, если: • Мини-приложение запущено с помощью кнопок в сообществе. • Исходная ссылка на приложение имела вид: `vk.com/app6909581_-166562603`. Параметр не используется в играх. |

## Передача произвольных параметров

При необходимости вы можете передавать произвольные параметры в игру или мини-приложение.

#### Запуск по прямой ссылке

При запуске приложения по прямой ссылке укажите параметры после символа `#` в адресной строке, например:

`https://vk.ru/app1234567#param1=12345`

Символы после `#` будут переданы приложению в URL-параметре `hash`. Этот параметр всегда идёт последним среди остальных передаваемых параметров. Все символы после него являются символами, которые были указаны после `#` в URL приложения.

Получить параметры можно и с помощью свойства `hash` объекта `window.location`. Для отслеживания изменений этого значения в приложении используйте события [`VKWebAppLocationChanged`](../../bridge/VKWebAppLocationChanged.md) и [`VKWebAppChangeFragment`](../../bridge/VKWebAppChangeFragment.md) библиотеки [VK Bridge](../../bridge/overview.md).

Использование знака вопроса (`?`) для передачи параметров при запуске по прямой ссылке не работает.

#### Параметры запуска в настройках приложения

Чтобы указать параметры запуска в настройках приложения, добавьте в URL знак вопроса и параметры, например:

`https://my-game.example.com/start-page?param1=12345`

Получить эти параметры вы можете так же, как и обычные параметры веб-страниц, например с помощью свойства `window.location.search` или с помощью события [`VKWebAppGetLaunchParams`](../../bridge/VKWebAppGetLaunchParams.md).

Использовать символы `#` в URL-адресах, которые указываются в настройках приложения, нельзя.
