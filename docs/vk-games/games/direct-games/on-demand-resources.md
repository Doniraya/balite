# Работа с ресурсами для iOS (ODR)

**C 13 августа 2024 года поддержка ODR для запуска игр на iOS больше не требуется.**

Раздел настроек ODR был удалён из панели управления игрой.

Параметр запуска `odr_enabled` больше не передаётся игре при старте.

Игры, опубликованные в каталоге для iOS, запускаются напрямую ВКонтакте в [WebView](https://dev.vk.com/ru/mini-apps/development/iframe-webview#%D0%9E%D1%81%D0%BE%D0%B1%D0%B5%D0%BD%D0%BD%D0%BE%D1%81%D1%82%D0%B8%20%D0%B7%D0%B0%D0%BF%D1%83%D1%81%D0%BA%D0%B0%20%D0%BD%D0%B0%20iOS). Чтобы попасть в каталог, игра должна пройти [модерацию](../settings/moderation.md).

Игры, которые не опубликованы в каталоге, тоже доступны на iOS, но открываются в мобильной версии сайта ВКонтакте ([m.vk.com](https://m.vk.com)).
