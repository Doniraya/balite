# Приглашения

Приглашения помогают вовлекать друзей в игру, чтобы играть вместе или соревноваться друг с другом. Это один из самых распространённых способов социального взаимодействия и прямой коммуникации.

По нашей статистике, приглашения дают до 15% всех запусков игры, а на мобильных устройствах до 25% входящего трафика в каталог игр приходится на переходы по приглашениям.

Находясь в игре, пользователь может выбрать друзей, которым хочет отправить приглашения.

## Ограничения

Механизм приглашений становится доступен игре только после [её публикации в каталоге](../../catalog/moderation.md). Неопубликованные игры могут рассылать приглашения только своим администраторам.

## Как реализовать

### Способ 1

Пользователь может отправить приглашения с помощью кнопки **Пригласить друзей** ВКонтакте и в Одноклассниках.

![Кнопка «Пригласить друзей» ВКонтакте](https://sun9-2.userapi.com/7qmwNU8u6qtFYFs9-UhWFf9W0EAvvUJ-KUkedw/DS-l_OjaW9Q.jpg)Кнопка «Пригласить друзей» ВКонтакте

![Кнопка «Пригласить друзей» в Одноклассниках](https://sun9-71.userapi.com/nwvaLJqdyQtAAfOPgbSo4_Ac88rARMvR6CzC8A/ZWWksYTl_eY.jpg)Кнопка «Пригласить друзей» в Одноклассниках

### Способ 2

Вы можете показать диалоговое окно с выбором друзей для приглашения в игру с помощью события [`VKWebAppShowInviteBox`](../../../bridge/VKWebAppShowInviteBox.md).

```javascript
bridge.send('VKWebAppShowInviteBox', { 
  requestKey: 'key-12345' /* Необязательный параметр. Ключ приглашения. */
  })
  .then( (data) => {
    if (data.success) {
      // Приглашение выслано ...
      // ...
      
      // Эти пользователи не получили сообщение
      // console.log('Приглашение не было отослано', data.notSentIds );
    }
  })
  .catch( (e) => { 
    let { error_code, error_reason } = e.error_data; 
    if( error_code == 4 && error_reason == 'User denied') {
      // Пользователь нажал «Отмена» в диалоге
      ...
    }  
  });
```

Если вы подключили библиотеку VK Bridge [в HTML-коде страницы](../../getting-started.md#2. Подключите VK Bridge), то в вызове надо использовать имя объекта `vkBridge` вместо `bridge`.

## Особенности использования

- Диалоговое окно показывает только тех друзей, которые ещё ни разу не запускали игру. Также оно скрывает пользователей, которым приглашение было выслано менее 1 недели назад.
- Если игра не опубликована в каталоге, она может отправлять уведомления только своим администраторам. В списке получателей не отображаются администраторы, которые уже запускали игру.
- Игра может поощрять отправителя приглашений, но только если кто-то из его друзей перейдёт в игру по приглашению. Награждать за сам факт отправки нельзя согласно [правилам платформы](../../../rules/mini-apps-rules.md#2.6. Социальные механики).
- Нельзя сообщать отправителю, кто именно пришёл в игру по его приглашению.

## Советы

- Чтобы администратор вернулся в список получателей приглашений, ему нужно удалить игру. Для этого в десктопной версии:
  - ВКонтакте нажать **Действия** → **Удалить**.
  - В Одноклассниках нажать **Ещё** → **Удалить**.
- При запуске игры из приглашения параметр события `requestKey` передаётся как URL-параметр с именем `vk_request_key`. Используйте его, чтобы предусмотреть в игре сценарий, соответствующий запросу, а также для отслеживания конверсии и отправителя приглашения. Подробнее — в разделе [Параметры запуска приложений ВКонтакте](https://dev.vk.com/ru/development/launch/launch-params).
- Чтобы отправить приглашение конкретному пользователю, используйте событие [`VKWebAppShowRequestBox`](../../../bridge/VKWebAppShowRequestBox.md) с текстом, приглашающим пользователя присоединиться к игре. Подробнее — в разделе [Запросы](requests.md).
