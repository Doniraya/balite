# Уведомления

Игра может отправлять пользователям уведомления — сообщения, которые напоминают пользователю об игре, помогают удерживать постоянных игроков и возвращать неактивных.

Уведомления можно увидеть в ленте в разделе **Игры** → **Профиль** десктопной версии сайта ВКонтакте. Также уведомления могут приходить в колокольчик и в виде push-уведомлений в Одноклассниках и ВКонтакте.

По умолчанию уведомления в игре включены. При первом запуске игры ВКонтакте пользователь увидит всплывающее сообщение о получении уведомлений.

- ВКонтакте пользователь может нажать **Настройки** во всплывающем сообщении и отключить уведомления. Либо сделать это позже из меню **Действия → Настройки**.
- В Одноклассниках пользователь может отключить уведомления, выбрав **Ещё → Оповещения**.

## Типы уведомлений

Игры ВКонтакте поддерживают уведомления следующих типов:

| Тип | Описание |
| :--- | :--- |
| [Разовые](single.md) | Сообщают пользователям об отдельных событиях, связанных с игрой, таких как: конкурсы, кампании или предложения к праздникам. |
| [Неактивным пользователям](automatic.md) | Напоминают пользователям об игре, если они не запускали её в течение нескольких дней. C помощью этих уведомлений игра также может сообщать пользователю, что его друг выполнил какую-либо миссию. |
| [Всем пользователям](mass.md) | Используются для массовой рассылки оповещений активным пользователям в честь какого-либо события. |

Далее в документации рассказывается о настройке уведомлений для игр ВКонтакте. В Одноклассниках также можно настроить оповещения пользователей. Подробнее — в разделе [Оповещения в Одноклассниках](../../../../ok/promotion/notifications.md).

## Ограничения

- Уведомления можно использовать в игре только после того, как она прошла модерацию и была [опубликована в каталоге](../../../catalog/moderation.md). Неопубликованные игры могут отправлять уведомления только своим администраторам.
- Для создания уведомлений [состояние игры](../../../settings/general/placement.md#Состояние для пользователей) должно быть **Включено**.
- В настройках профиля пользователя ВКонтакте и Одноклассников должны быть включены уведомления от игр и приложений.
