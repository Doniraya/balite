# Доступ к приложению (настройки игр)

Раздел **Доступ к приложению** отображается для [администраторов игры с частичным доступом](managers.md#Администратор с частичным доступом). В нём они могут просмотреть назначенные права и выйти из администрирования игры.

**Чтобы открыть раздел:**

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).
2. Откройте настройки нужной игры.
3. В меню слева выберите **Доступ к приложению**.

## Доступ

Раздел доступен [администраторам игры с частичным доступом](managers.md#Администратор с частичным доступом).

Для [создателя](managers.md#Создатель) и [администраторов с полным доступом](managers.md#Администратор с полным доступом) раздел недоступен. Вместо него они видят другой раздел — [Администраторы](managers.md).

## Действия в разделе

### Выход из администрирования

Чтобы выйти из списка администраторов мини-приложения, нажмите **Отказаться от доступа**.

### Изменение доступа

Администраторы с частичным доступом не могут изменить права доступа себе или другим администраторам. Чтобы это сделать, обратитесь к [создателю](managers.md#Создатель) игры либо к [администратору с полным доступом](managers.md#Администратор с полным доступом).

Чтобы узнать, кто создатель приложения, нажмите на ссылку **создатель** в верхней части раздела.
