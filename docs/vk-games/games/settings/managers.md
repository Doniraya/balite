# Администраторы (настройки игр)

Администраторы — пользователи, авторизованные на [единой платформе](https://dev.vk.com/ru/admin/apps-list) по VK ID, которые занимаются разработкой, тестированием и поддержкой работы игры. Они могут, например, менять настройки игры, запускать её, когда она отключена для остальных пользователей, проверять работу платежей.

В разделе **Администраторы** вы можете просматривать список администраторов и работать с ним: добавлять новых пользователей, изменять настройки у существующих, передавать доступ.

**Чтобы открыть настройки администраторов:**

1. Перейдите в [список приложений](https://dev.vk.com/ru/admin/apps-list).
2. Откройте настройки нужной игры.
3. В меню слева выберите **Администраторы**.

## Доступ

Редактировать список администраторов может:

- [Создатель](#Создатель) игры.
- [Администратор с полным доступом](#Администратор с полным доступом).

Для [администраторов с частичным доступом](#Администратор с частичным доступом) раздел недоступен. Вместо него они видят другой раздел — [Доступ к приложению](access-to-app.md).

## Виды администраторов

Всеми правами на игру обладает пользователь с правами создателя. Остальные администраторы могут иметь полный или частичный доступ к настройкам игры.

### Создатель

**Создатель** — это главный администратор игры. Он обладает доступом ко всем настройкам. Только он может:

- Выводить средства, полученные за показы рекламы или продажу товаров.
- Публиковать игру на [других площадках](general/other-sites.md).
- Удалить игру с платформы.

Управлять списком администраторов может не только создатель, но и [администратор с полным доступом](#Администратор с полным доступом).

В списке администраторов может быть только один пользователь с правами создателя. Изначально это пользователь, который зарегистрировал игру на платформе VK Mini Apps.

### Администратор с полным доступом

У администраторов этого типа есть доступ к настройкам игры, но они не обладают исключительными правами [создателя](#Создатель).

У администраторов с полным доступом есть права на все разделы настроек, которые присутствуют в [частичном](#Администратор с частичным доступом) доступе. Кроме того, администратор с полным доступом может:

- Редактировать список администраторов (но не может переназначить создателя).
- Редактировать [список тестировщиков](test-groups.md).
- Подавать [заявку на размещение в каталоге](moderation.md).
- Тестировать игру до прохождения модерации на всех подключённых площадках.
- Обращаться в Поддержку.

### Администратор с частичным доступом

Права администратора с частичным доступом складываются из одного или нескольких прав, которые им выдал создатель или администратор с полным доступом.

| Права | Описание |
| :--- | :--- |
| **Тестирование** | Даёт возможность запускать на всех подключённых площадках игру, у которой [состояние для пользователей](general/placement.md#Состояние для пользователей) установлено в **Отключено**. Доступные разделы настроек — только [Доступ к приложению](access-to-app.md). Другие разделы администратору с этим правом недоступны. |
| **Редактирование** | Даёт возможность частичной настройки и редактирования информации об игре. | **Платежи** | Даёт возможность настраивать платежи, просматривать статистику транзакций и уведомлений и выводить голоса. Доступные разделы настроек: • [Монетизация](monetization.md) • Разделы группы [Платежи](payments/setting-up.md) • [Статистика \| Платежи](stats/payments.md) • [Доступ к приложению](access-to-app.md) |

Доступные разделы настроек: • [Статистика \| Аудитория](stats/audience.md) • [Статистика \| Запросы к API](stats/api-requests.md) • [Статистика \| Рейтинг популярности](stats/popularity-rating.md) • [Доступ к приложению](access-to-app.md) |
| **Рекламная монетизация** | Даёт возможность просматривать статистику показов рекламы и начислений за них, а также выводить средства, полученные за показ рекламы. Доступные разделы настроек: • [Статистика \| Рекламная монетизация](stats/monetization.md) • [Доступ к приложению](access-to-app.md) |

## Редактирование списка администраторов

Добавлять новых администраторов, изменять их права или удалять может [создатель](#Создатель) либо [администратор с полным доступом](#Администратор с полным доступом).

Создателю доступны все операции над списком. Администраторам с полным доступом — все действия над другими администраторами, кроме создателя.

### Добавить администратора

- Для добавления нового администратора нажмите **Добавить** и укажите ссылку на его страницу ВКонтакте. Подойдёт как обычная ссылка вида `https://vk.com/id743784474`, так и ссылка с [никнеймом](https://vk.com/faq18038).
- После того как вы подтвердите добавление администратора, платформа отправит ему приглашение. Пользователь станет администратором только после того, как примет приглашение.

Пользователи, которые пока не приняли приглашение, отображаются в списке администраторов, но администраторами не являются.

### Удалить администратора

Удалить администраторов из списка могут создатель или администратор с полным доступом. Для этого нажмите иконку с мусорной корзиной напротив нужного администратора.

Удалить создателя из списка администраторов нельзя. Если создатель хочет выйти из администрирования, он должен [передать свои права](#Передача управления) кому-либо из администраторов с полным доступом и затем отказаться от администрирования самостоятельно либо попросить нового создателя об удалении.

## Передать права создателя

[Создатель](#Создатель) может передать права администратору с полным доступом. Для этого в разделе **Администраторы** нужно нажать **Передать доступ** и выбрать из списка одного из администраторов с полным доступом.

Выбранный администратор должен принять приглашение и подтвердить переход прав к нему. До этого момента исключительные права остаются за текущим создателем.

После подтверждения перехода прав создатель становится администратором с полным доступом.

**Важно!**

- Если для игры настроена [интеграция с Одноклассниками](../../ok/publishing.md#Шаг 2. Подключите приложение к Одноклассникам), создателем можно назначить только пользователя, который имеет права разработчика на платформе Одноклассники. Подробнее — в разделе [Администрирование приложений](../../ok/administrators.md#Связать аккаунты разработчика VK ID и OK ID).
- Если в приложении подключена монетизация, при передаче прав создателя укажите актуального исполнителя в кабинете выплат, чтобы продолжить зарабатывать на подключённых инструментах и выводить средства. Подробнее — в разделе [Вывод средств](../monetization/withdrawal/overview.md).

## Выход из администрирования

Администраторы с полным и частичным доступом могут отказаться от администрирования самостоятельно. Чтобы сделать это, просто нажмите **Отказаться от доступа** напротив своего имени в списке администраторов.

Администраторы с полным доступом видят эту кнопку в разделе **Администрирование**. Администраторам с частичным доступом кнопка доступна в разделе [Доступ к приложению](access-to-app.md).

Создатель игры выйти из администрирования не может. Сначала он должен [передать свои права](#Передача управления) кому-либо из администраторов с полным доступом.
