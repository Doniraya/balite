# VK Games — Панель управления

При помощи панели управления вы можете создавать и настраивать игры.

Чтобы открыть список доступных игр и мини-приложений, откройте портал для разработчиков — [dev.vk.ru](https://dev.vk.com) — и выберите **Приложения** в верхнем меню. Или перейдите по прямой ссылке:

► [https://dev.vk.ru/admin/apps-list](https://dev.vk.ru/admin/apps-list)

Затем выберите игру из списка и нажмите **Настройки**. Откроется панель управления игрой.

## Доступ

Настройки игры доступны её [администраторам](managers.md). Доступ к настройкам игры может быть полным или частичным.

## Удалить игру

Удалить игру может администратор с правами [создателя](managers.md#Создатель). Кнопка удаления расположена на странице [Настройки → Размещение](general/placement.md).

Удалённую игру нельзя восстановить.

## Вопросы и ответы

#### Я не вижу некоторых разделов. Что делать?

Видимость разделов зависит от прав, которые пользователь получил, когда его добавили в список администраторов. Попросите пользователя с правами [создателя](managers.md#Создатель) поменять вам уровень доступа к игре.

Кроме того, некоторые разделы могут быть скрыты, если игра не размещена в [каталоге игр](https://vk.com/games).

#### Где найти ID игры?

Идентификатор игры отображается в настройках игры, в верхнем правом углу.

#### Как запустить игру со страниц настроек?

#### Можно ли выйти из управления?

Да. Это можно сделать в разделе [Администраторы](managers.md).

Создатель игры должен сначала [передать права создателя](managers.md#Передача управления создателем) другому администратору и только потом выйти из управления.
