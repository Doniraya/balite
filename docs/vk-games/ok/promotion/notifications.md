# Оповещения в Одноклассниках

Вы можете отправлять пользователям в Одноклассниках оповещения — сообщения, которые напоминают о приложении, помогают удерживать активных пользователей и возвращать тех, кто давно не открывал приложение.

Для отправки оповещений используйте методы API Одноклассников:

- [`notifications.sendSimple`](notifications/user.md#Отправить оповещение одному пользователю) — чтобы отправить оповещение одному пользователю по его идентификатору.
- [`notifications.sendList`](notifications/user.md#Отправить массив оповещений разным пользователям) — чтобы отправить массив оповещений разным пользователям по их идентификаторам одним запросом.
- [`notifications.sendMass`](notifications/group.md) — чтобы отправить оповещение пользователям приложения, чьи профили соответствуют заданным критериям.

Подробнее о работе с API Одноклассников — в разделе [Вызовы API на стороне сервера](../development/api.md#Вызовы API на стороне сервера).
